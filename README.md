Ember Coast is a 3D open-world crime game in a dusk-ember coastal city with a volcano on the horizon: drive and steal cars, outrun a 5-star police dispatch with helicopters and roadblocks, complete 10 story missions, 5 syndicate contracts and 3 street races, and build a player-driven economy — buyable businesses (bar, garage, nightclub, 3 levels each), an upgradeable safehouse, and dynamic profit scaling with district standing and territory — plus two crew members, territory income, stunt ramps with slow-mo, district standings, garage upgrades, radio stations, saves, HUD and minimap — all playable in a desktop browser from static files.

## Run it

```sh
node main.ts
```

Then open `out/game/index.html` in desktop Chrome to play.
